# Pliki paczki

Umieszczaj tutaj podfoldery `mods/`, `config/`, `resourcepacks/`, `shaderpacks/`, `defaultconfigs/`, `kubejs/` i `scripts/`.

Folder `pack/` jest celowo ignorowany przez Git — nie wrzucaj dużych plików JAR do repozytorium z kodem. Hostuj paczkę na publicznym HTTPS/CDN, a potem wygeneruj manifest poleceniem `npm run manifest:build`.
